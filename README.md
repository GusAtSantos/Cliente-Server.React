## 🚀 How to run
```bash

cd Cliente-Server.React

# Backend
cd [server-folder]
npm install
npm start

# Frontend (new terminal)
cd [client-folder]
npm install
npm start
```
Create a `.env` file with: `[VARIABLE_NAME=value]`
